# Security Policy

## Reporting a vulnerability

Please do not disclose security issues publicly before maintainers have time to respond.

If you find a vulnerability, open a private security advisory on GitHub or contact the project maintainers directly. Include:

- Affected component
- Steps to reproduce
- Impact
- Suggested fix, if available

## Secret handling

Never commit real API keys, JWTs, wallet seeds, private keys, or `.env` files. Use example placeholders in committed files and rotate any credential that has been exposed in git history.

## Supported versions

The main branch is the actively supported development version.
